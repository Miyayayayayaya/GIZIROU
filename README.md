# 議事郎（Meeting Follow-up AI Agent）

社外の人を含む会議の終了後に発生する、議事録の清書・情報整理・フォローアップメール作成・次回会議の予定共有をAIで支援するWebアプリです。

## 背景・課題

社外の人との会議後には、以下のような作業が発生します。

- 会議内容を整理する
- 社外向けに議事録を清書する
- 決定事項をまとめる
- ToDo・担当者・期限を整理する
- 社外に共有してよい内容か確認する
- フォローアップメールを作成する
- 次回会議が決まった場合、予定を共有する

これらの作業には時間がかかり、会議が多い人ほど負担が大きくなります。

本アプリでは、この**「会議終了後からフォローアップメール送信まで」**をAI Agentによって効率化することを目指します。

## 想定ユーザー

社外の人との会議が多いビジネスパーソンを想定しています。

- B2B営業
- コンサルタント
- SIerのSE・PM・PMO
- 取引先との会議が多い職種

## 主な機能

### 1. Googleアカウントでログイン

アプリを開いたら、最初にGoogle OAuthでログインします。認証に成功したユーザーだけが文字起こし入力、AI分析、会議履歴、メール送信を利用できます。

MVPでは独自のID・パスワードを発行せず、Googleアカウントを利用します。ログイン状態の保持、ログアウト、ログイン中ユーザーのメールアドレス表示に対応します。

### 2. 文字起こし入力

会議の文字起こしデータをアプリに入力します。

### 3. AIによる会議内容の整理

入力された文字起こしをAIが分析し、以下の情報を生成・抽出します。

- 社外向け議事録
- 決定事項
- ToDo
- 担当者
- 期限
- 社外共有に注意が必要な内容
- 曖昧な内容
- フォローアップメール

### 4. 次回会議の検出

会議中に次回会議が決まった場合、AIが以下の情報を抽出します。

- 次回会議の有無
- 会議タイトル
- 日付
- 開始時刻
- 終了時刻

日時が確定している場合は、送信前確認画面のボタンから、ログイン中ユーザー自身のGoogle Calendarへ予定を追加できます。同じ会議を繰り返し登録しないよう、作成済みのイベントIDをSQLiteへ保存します。また、フォローアップメールには受信者向けのGoogle Calendar追加リンクを含めます。

日時が曖昧な場合は、AIが勝手に日時を決定せず、送信前に警告を表示します。

### 5. 送信前確認

AIが生成した内容をそのまま自動送信することはありません。

メール送信前にユーザーが以下を確認し、必要に応じて修正できます。

- 宛先
- 件名
- メール本文
- 議事録
- 決定事項・ToDo
- AIによる警告
- 次回会議情報

### 6. 会議履歴の保存

AIの解析が完了した会議について、文字起こし・議事録・分析結果・メール下書きをSQLiteへ保存します。

ブラウザを閉じたりアプリを再起動した後も、同じPC・サーバー環境であれば履歴を再確認できます。MVPではログイン済みユーザーだけが履歴機能へアクセスできるようにします。

ただし、MVP時点では保存データをユーザーごとに分離しない可能性があります。ユーザーごとの履歴分離が完成するまでは、一人での利用またはアクセスを制限した開発・デモ環境で利用します。

### 7. メール送信

確認・承認後、ログイン・認可中のGoogleアカウントのGmailからフォローアップメールを送信します。

#### Google OAuth設定

`.env.example` を `.env` にコピーし、次を設定してください。`.env`、Client Secret、認可トークンはGit管理しません。

- `FLASK_SECRET_KEY`: 十分に長いランダム文字列
- `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`: Google Auth Platformで作成したWeb applicationの認証情報
- `GOOGLE_OAUTH_REDIRECT_URI`: Google Cloud Consoleに登録したURIと完全一致するURL（ローカル開発では `http://localhost:5001/oauth2callback`）

Google Cloud側ではGmail APIとGoogle Calendar APIを有効にしてください。アプリを開いたら「Googleでログイン」を選択し、メール送信とカレンダー予定作成の権限を認可します。Calendar権限の追加前にログイン済みだった場合は、一度Google連携をやり直してください。

認可トークンはローカルの `instance/oauth_tokens.sqlite3` に保存されます。ローカルでは必ず `http://localhost:5001` を使用し、`127.0.0.1` と混在させないでください。

## 処理フロー

```text
Googleアカウントでログイン
 ↓
会議
 ↓
文字起こし
 ↓
AIによる分析
 ├─ 議事録の清書
 ├─ 決定事項・ToDo抽出
 ├─ 社外共有注意情報の検出
 ├─ 曖昧な内容の検出
 ├─ 次回会議の検出
 └─ フォローアップメール生成
 ↓
SQLiteへ会議履歴を保存
 ↓
送信前確認・修正
 ↓
承認
 ↓
メール送信
```

## データについて

MVPでは、会議の文字起こしとAIの解析結果をローカルのSQLiteへ保存します。

保存対象は以下です。

- 文字起こし
- 社外向け議事録
- 決定事項・ToDo・警告
- 次回会議情報
- フォローアップメールの下書き

基本的に、以下の処理を行います。

```text
文字起こし入力 → AI処理 → SQLiteへ保存 → 確認・編集 → メール送信
```

ブラウザを閉じてもデータは消えません。ただし、SQLiteのDBファイルを削除した場合や、別のPC・サーバーへ移動した場合は同じ履歴を参照できません。

MVPではGoogle OAuthによるログインと未ログイン時のアクセス制限を行います。ただし、会議履歴をユーザーごとに分離する機能はMVP後とします。そのため、ユーザーごとのデータ分離が完成するまでは不特定多数が利用する一般公開環境では使用せず、一人での利用またはアクセスを制限した開発・デモ環境に限定します。一般公開する場合は、ユーザーごとのアクセス制御、保存期間、削除方法を追加する必要があります。

また、利用するLLM APIや外部サービス側でのデータの取り扱いについては、それぞれのサービスの仕様を確認する必要があります。

## チーム構成

### Frontend

ユーザーが操作する画面を担当します。

- 文字起こし入力画面
- ログイン画面、ログイン中ユーザー表示、ログアウトUI
- 送信前確認画面
- 議事録・メールの表示・編集
- 警告や次回会議情報の表示

### AI

会議内容をAIで処理する部分を担当します。

- 議事録生成
- 決定事項・ToDo抽出
- 社外共有注意情報の検出
- 曖昧な情報の検出
- 次回会議情報の抽出
- フォローアップメール生成

### Backend

Flaskを中心に各機能を接続します。

- 入力データの受け取り
- 未ログイン時のルートアクセス制限
- AI処理の呼び出し
- AI結果の受け渡し
- ルーティング・API
- Calendar追加リンク生成
- SQLiteへの会議履歴保存
- 保存データの取得・削除
- エラー処理

### Integration

外部サービスとの連携を担当します。

- Google OAuthによるログイン・ログアウト・セッション維持
- Gmail API
- メール送信
- Googleサービスとの連携
- 結合テスト

## 開発方針

- まずMVPの完成を優先する
- Issue単位で開発を進める
- AIが生成したコードも担当者が内容を理解する
- 不必要な機能を増やさない
- AIによるメールの完全自動送信は行わない
- ユーザーによる最終確認を必須とする
- Googleログインをアプリ利用の最初のステップにする
- 未ログインユーザーに会議分析・履歴・メール送信を利用させない
- 認証とユーザーごとのデータ分離が完成するまでは一般公開しない

## MVP

まずは以下の一連のフローが動作することを目標とします。

```text
Googleでログイン → 文字起こしを入力 → AIが議事録・メールを生成 → SQLiteへ履歴を保存 → 送信前に確認・修正 → ログイン中のGoogleアカウントからメールを送信
```

次回会議の日時が確定している場合は、自分のGoogle Calendarへワンクリックで追加でき、メールには参加者向けの追加リンクも含めます。

MVPでは、Googleログイン、ログイン状態の保持、ログアウト、未ログイン時のアクセス制限、ログイン中ユーザーのメールアドレス表示を必須とします。保存した会議履歴は、同じPC・サーバー環境でアプリを再度開いたときに確認できることをMVPの対象とします。

ユーザーごとの履歴分離、クラウド上でのDB共有、INIAD以外を含む組織単位のアクセス制御はMVP後に対応します。INIAD固有の条件が必要な場合も、アプリへ直接埋め込まず設定として分離します。
