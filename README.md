# Meeting Follow-up AI Agent

社外の人を含む会議の終了後に発生する、議事録の清書・情報整理・フォローアップメール作成・次回会議の予定共有をAIで支援するWebアプリです。

## 背景・課題

社外の人との会議後には、以下のような作業が発生します。

- 会議内容を整理する
- 社外向けに議事録を清書する
- 決定事項をまとめる
- ToDo・担当者・期限を整理する
- 社外に共有してよい内容か確認する
- フォローアップメールを作成する
- 次回会議が決まった場合、予定を共有する

これらの作業には時間がかかり、会議が多い人ほど負担が大きくなります。

本アプリでは、この**「会議終了後からフォローアップメール送信まで」**をAI Agentによって効率化することを目指します。

## 想定ユーザー

社外の人との会議が多いビジネスパーソンを想定しています。

- B2B営業
- コンサルタント
- SIerのSE・PM・PMO
- 取引先との会議が多い職種

## 主な機能

### 1. 文字起こし入力

会議の文字起こしデータをアプリに入力します。

### 2. AIによる会議内容の整理

入力された文字起こしをAIが分析し、以下の情報を生成・抽出します。

- 社外向け議事録
- 決定事項
- ToDo
- 担当者
- 期限
- 社外共有に注意が必要な内容
- 曖昧な内容
- フォローアップメール

### 3. 次回会議の検出

会議中に次回会議が決まった場合、AIが以下の情報を抽出します。

- 次回会議の有無
- 会議タイトル
- 日付
- 開始時刻
- 終了時刻

日時が確定している場合は、Google Calendarに予定を追加するためのリンクを生成し、フォローアップメールに追加します。

日時が曖昧な場合は、AIが勝手に日時を決定せず、送信前に警告を表示します。

### 4. 送信前確認

AIが生成した内容をそのまま自動送信することはありません。

メール送信前にユーザーが以下を確認し、必要に応じて修正できます。

- 宛先
- 件名
- メール本文
- 議事録
- 決定事項・ToDo
- AIによる警告
- 次回会議情報

### 5. 会議履歴の保存

AIの解析が完了した会議について、文字起こし・議事録・分析結果・メール下書きをSQLiteへ保存します。

ブラウザを閉じたりアプリを再起動した後も、同じPC・サーバー環境であれば履歴を再確認できます。MVPではログイン機能を必須とせず、一人での利用またはアクセスを制限した開発・デモ環境での利用を想定します。

### 6. メール送信

確認・承認後、Gmailを利用してフォローアップメールを送信します。

## 処理フロー

```text
会議
 ↓
文字起こし
 ↓
AIによる分析
 ├─ 議事録の清書
 ├─ 決定事項・ToDo抽出
 ├─ 社外共有注意情報の検出
 ├─ 曖昧な内容の検出
 ├─ 次回会議の検出
 └─ フォローアップメール生成
 ↓
SQLiteへ会議履歴を保存
 ↓
送信前確認・修正
 ↓
承認
 ↓
メール送信
```

## データについて

MVPでは、会議の文字起こしとAIの解析結果をローカルのSQLiteへ保存します。

保存対象は以下です。

- 文字起こし
- 社外向け議事録
- 決定事項・ToDo・警告
- 次回会議情報
- フォローアップメールの下書き

基本的に、以下の処理を行います。

```text
文字起こし入力 → AI処理 → SQLiteへ保存 → 確認・編集 → メール送信
```

ブラウザを閉じてもデータは消えません。ただし、SQLiteのDBファイルを削除した場合や、別のPC・サーバーへ移動した場合は同じ履歴を参照できません。

MVPではログイン機能とユーザーごとのデータ分離を行いません。そのため、不特定多数がアクセスできる公開環境では使用せず、一人での利用またはアクセスを制限した開発・デモ環境に限定します。一般公開する場合は、Google OAuth等による認証、ユーザーごとのアクセス制御、保存期間、削除方法を追加する必要があります。

また、利用するLLM APIや外部サービス側でのデータの取り扱いについては、それぞれのサービスの仕様を確認する必要があります。

## チーム構成

### Frontend

ユーザーが操作する画面を担当します。

- 文字起こし入力画面
- 送信前確認画面
- 議事録・メールの表示・編集
- 警告や次回会議情報の表示

### AI

会議内容をAIで処理する部分を担当します。

- 議事録生成
- 決定事項・ToDo抽出
- 社外共有注意情報の検出
- 曖昧な情報の検出
- 次回会議情報の抽出
- フォローアップメール生成

### Backend

Flaskを中心に各機能を接続します。

- 入力データの受け取り
- AI処理の呼び出し
- AI結果の受け渡し
- ルーティング・API
- Calendar追加リンク生成
- SQLiteへの会議履歴保存
- 保存データの取得・削除
- エラー処理

### Integration

外部サービスとの連携を担当します。

- Google OAuth
- Gmail API
- メール送信
- Googleサービスとの連携
- 結合テスト

## 開発方針

- まずMVPの完成を優先する
- Issue単位で開発を進める
- AIが生成したコードも担当者が内容を理解する
- 不必要な機能を増やさない
- AIによるメールの完全自動送信は行わない
- ユーザーによる最終確認を必須とする
- MVPの履歴保存はログイン不要の単一利用環境を前提とする
- 認証とユーザーごとのデータ分離が完成するまでは一般公開しない

## MVP

まずは以下の一連のフローが動作することを目標とします。

```text
文字起こしを入力 → AIが議事録・メールを生成 → SQLiteへ履歴を保存 → 送信前に確認・修正 → メールを送信
```

次回会議が決まっている場合は、Google Calendarへの追加リンクもメールに含めます。

保存した会議履歴は、同じPC・サーバー環境でアプリを再度開いたときに確認できることをMVPの対象とします。ログイン、ユーザーごとの履歴分離、クラウド上でのDB共有はMVP後に対応します。
